小序 · 离线网页版（Windows）

解压整个文件夹后，双击 Start-Windows.cmd。它使用 Windows 自带 PowerShell，在本机 127.0.0.1:4178 提供静态页面并打开浏览器，不需要互联网、Node.js、账号或管理员权限。请保留命令窗口；关闭即停止页面文件服务。脚本的 ExecutionPolicy Bypass 只用于这次 PowerShell 进程，不更改系统策略。

建议使用近期版本的 Microsoft Edge 或 Chrome。第一次打开等待几秒，离线资源会完整缓存；随后可以通过浏览器菜单“安装此站点为应用”。应用运行、任务保存都在本机，即使断网也能使用。不要直接双击 app/index.html，浏览器对文件地址有存储与模块限制。

任务保存在当前浏览器的网站数据中。固定使用 http://127.0.0.1:4178/，不要随意更换 localhost、端口、浏览器或配置文件；这些会产生不同的存储空间。换电脑请在“设置与备份”导出 JSON，再在目标电脑导入。支持之前“小序”的备份。

快速录入：明天下午3点 准备会议 #工作 @专注 p1
可识别：今天、明天、后天、下周一、2026-10-25、15:30、下午3点、每天、每个工作日、每周三、每月、每年、p1–p4。#项目和@标签必须已经存在；无法识别的内容保留为标题。点击识别结果可取消识别。Q 快速添加，/ 搜索全部任务，Esc 关闭。

0.3.0 新增：过滤器与标签管理、活动日志、已完成任务入口，以及与整体设计一致的日期时间日历。过滤器例子：active & (@专注 | p1)、#工作 & 无日期、completed。过滤器查询独立匹配全部任务；只看待办时加 active。标签改名同步过滤器，删除标签保留任务。日志从启用后的操作开始记录，并随备份导出。视图菜单会记住显示已完成、紧凑和排序设置。

日期弹层提供今天、明天、一周后和下周一，月份切换、时分输入、清除和应用。选择后点击“应用日期”确认；Esc 只关闭日历，未应用的选择会放弃。截止时间和提醒时间可分别设置。

0.4.0 新增：“预览”支持日、周、月切换，左右翻页与回到今天；周从周一开始，月历选择日期后查看完整清单。点击日期中的任务可编辑，按所选日期添加时默认09:00。显示已完成和排序设置会同步到日历。没有截止日期的任务可前往全部任务查看。

0.5.0 新增：项目与收件箱支持版块管理，创建、改名、调整顺序和删除保留任务。任务区切换列表/看板，并按版块、日期、优先级、项目、标签或不分组查看；每个页面记住自己的设置。卡片可点击编辑、勾选完成、跨列拖动，或使用“移动到分组”下拉操作。列内新增继承分组条件，任务详情可选版块。日期列只支持移入今天、明天、无日期，重复任务不能直接移入无日期；未分配日期以外的具体日期可在任务详情中修改。移动操作和版块管理会记录日志。

关闭所有浏览器进程后的准时通知不在网页能力承诺范围。清理浏览器数据前请先备份。本版本已在 macOS 浏览器进行验证，Windows 启动脚本尚未实机验证。
