# 小序 · 离线待办

在原项目 todo-ltn（8361350）的基础上继续开发，参考 Todoist 的列表布局与快速添加体验。任务、项目、标签、提醒和固定日历重复规则均在本机运行；无需账号、租户、服务端接口或同步服务。没有复制 Todoist 的应用代码和素材。

## 在线使用与源码

源码仓库：[chaolinhan/xu-todo](https://github.com/chaolinhan/xu-todo)。GitHub Pages 入口：[小序](https://chaolinhan.github.io/xu-todo/)。在线版仅托管静态页面，任务仍保存在各自浏览器，不会上传到 GitHub。首次联网打开并等待离线缓存就绪后可离线使用。

在线地址与本机 `127.0.0.1:4178` 属于不同存储空间，任务不会自动迁移；请在原地址导出 JSON，再到目标地址导入。部署只上传构建后的静态文件，不包含浏览器任务、REA 本机诊断与原始证据。

每次推送 `main` 时，GitHub Actions 安装锁定依赖、运行测试、构建 `/xu-todo/` 子路径并部署。可以在 Actions 页手动运行工作流。部署配置见 `.github/workflows/pages.yml`；本地检查在线构建用 `npm run build:pages`，输出为 `dist-pages/`，不覆盖本机根路径构建和 Windows 离线包。普通 `npm run build` 仍为本机根路径构建。参考 [Vite 静态部署说明](https://vite.dev/guide/static-deploy.html) 和 [GitHub Pages 自定义工作流](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)。

## 直接使用

Windows：解压 `release/xiaoxu-offline-windows.zip`，双击 `Start-Windows.cmd`，用 Edge 或 Chrome 打开自动弹出的本机页面。包内使用系统自带 PowerShell 仅向 127.0.0.1:4178 提供静态文件，不需要 Node.js 或互联网。脚本只为本次 PowerShell 进程设置执行策略，不修改系统策略；受组织管理的电脑可能限制运行，请遵守本机策略。Windows 脚本已检查，但尚未在 Windows 实机运行。

源码预览：安装 Node.js 22.19+ 或 24.11+ 后，执行 `npm ci`、`npm run dev`。生产版执行 `npm run build`、`npm run preview`，固定地址为 http://127.0.0.1:4178/ 。开发版不注册离线缓存，离线验收需使用生产构建。

## 本轮体验

浅色侧栏、白色任务区、红色强调；收件箱、今天、日/周/月预览、全部任务、项目和标签。新增过滤器与标签管理、活动日志、独立已完成视图。支持列表内连续录入、Q 快速添加、/ 全局搜索、任务详细编辑、完成与撤销、折叠分组、已完成显示开关、优先级排序和紧凑列表，三个显示偏好会在本机记住。

输入 `明天下午3点 准备会议 #工作 @专注 p1`，添加前会显示日期、项目、标签和优先级；点击已识别词可改为普通标题文字。当前语法要求各段之间用空格分隔，支持今天、明天、后天、下周一、周三、2026-10-25、10月25日、15:30、下午3点半、每天、每个工作日、每周三、每月、每年。项目与标签须先创建，未识别文本与无效日期保留在标题中，不会自动创建集合。

提醒默认跟随截止时间，手动清空后保持关闭。重复任务完成时保留本次记录、创建下一个未来实例；错过的周期不补建。月末夹取保留日期锚点，防止恢复旧实例后重复生成下一实例。

## 过滤器、标签与操作记录（0.3.0）

在“过滤器与标签”里新建、编辑、删除过滤器，保存后可从侧栏直接打开。编辑时即时显示匹配数量，语法错误和不存在的项目/标签会明确提示，不会变成匹配全部任务。支持 `&`（同时满足）、`|`（任一满足）、`!`（排除）和括号，优先级依次为 `!`、`&`、`|`。例如 `active & (@专注 | p1)`、`#工作 & 无日期`、`completed`；含空格或符号的名称用双引号，例如 `@"等待 回复"`。

支持条件：`active` / 未完成、`completed` / 已完成、`all` / 全部、p1–p4、今天、明天、逾期、未来7天（包含今天的七个本地日历日）、无日期、无标签、重复任务、`#项目名称`、`@标签名称`、`search:关键词`，以及编辑器帮助中对应的英文写法。日期条件比较截止日期；`completed & 未来7天` 不表示最近七天完成，而是已完成且截止日期在未来七天内。过滤器独立匹配所有任务，若只需要待办请加入 `active`。这是本项目的离线查询语言，并非 Todoist 全部查询语法的实现。

标签支持创建、改名、换色、删除。改名保留任务关联，并自动更新过滤器中的完整标签引用；删除标签仅移除关联，任务保留，引用已删除标签的过滤器会显示错误并提示重新编辑。独立“已完成”视图按完成时间倒序排列，点击勾选按钮可以恢复任务；其他任务视图可通过“视图 → 显示已完成任务”一同查看。

“活动日志”记录启用后的任务添加、编辑、完成、恢复、删除、撤销完成，以及标签、过滤器、项目创建和备份导入。任务删除后仍保留当时的标题和项目快照。支持按操作、项目、最近7/30天筛选及文字搜索，多于50条可继续加载；不会为升级前的任务伪造操作历史。新增字段包含在 JSON 备份中，旧备份缺失这些字段时照常读取。

快速添加、截止时间、提醒时间统一使用自定义日历弹层：月份切换、今天/明天/一周后/下周一、时分输入、清除和应用。选择过程需点击“应用日期”才写入任务草稿，Esc 只关闭当前日历，方向键可移动日期；外部点击放弃本次未应用选择。

## 日、周、月速览（0.4.0）

“预览”提供日、周、月切换，默认周视图并记住上次模式。用左右箭头按当前粒度翻页，“今天”返回本地当天。周视图从周一开始，月视图展示完整的日历周；选择日期后，下方显示该日完整任务清单。日历中的任务可直接打开编辑，清单保留完成/恢复能力，为所选日期添加任务时默认使用该日09:00，仍可自行调整。

任务按照截止日期在本地时区归类，“显示已完成”与排序偏好同步应用到数量、速览和清单；无日期任务通过提示入口前往全部任务查看。重复任务仅显示已经存在的实例，后续实例按原有完成规则生成。月份翻页在月末夹取合法日期，不会因31日跳过二月。日历可通过左右/上下方向键选择日期、PageUp/PageDown翻页，窄屏保留日历数量与完整日清单。查询模式的全局搜索保持原有行为，不受当前日期范围限制。

## 分组和看板（0.5.0）

在收件箱或任一项目中点“管理版块”，建立自己的任务分组；可以改名、上移/下移调整顺序，删除版块只会把任务放回“未分组”。任务详情里也能选择所属版块，切换所属项目时会清除旧版块。重复任务生成下一次实例时沿用版块。

任务区提供“列表 / 看板”切换和“分组”选项，支持版块、日期、优先级、项目、标签、不分组。每个页面分别保存布局和分组设置，搜索结果也有独立设置，日周月日期预览保持原有模式。多标签任务会出现在每个对应标签组中，页面总数仍按任务去重。旧任务没有版块时自动进入未分组。

看板卡片可点击编辑、完成/恢复，通过拖动跨列移动，也可使用卡片下方“移动到分组”下拉控件在触屏或键盘上操作。版块列内新增会继承项目和版块，优先级、标签、日期列内新增同样继承对应条件。移动到其他项目会清除原版块；标签之间移动只替换来源标签，保留其他标签，移入“无标签”会清空全部标签。完成与恢复仍保留日志，完成按钮保持独立操作。

日期分组可移动到今天、明天或无日期，保留原时分与提醒相对截止时间的偏移，关闭的提醒保持关闭；逾期、接下来及已完成组仅用于展示，请通过任务详情修改具体日期或勾选完成。重复任务不能直接拖到无日期，需先在详情中取消重复。日期移动后重复规则锚点跟随新日期。自动分组不提供列内手动排序，沿用日期/优先级排序选择。若任务移动后不再符合当前视图或过滤器，会从当前页面退出，任务仍然保留。

版块管理和分组移动记录在本地日志，并包含在备份中。新增字段均可选，旧备份照常读取。桌面看板横向展示，窄屏只在看板列区域横向滚动。

## 离线与数据边界

整个应用和字体都随包提供。生产版在首次正常打开时缓存全部静态资源；侧栏会显示缓存是否就绪。Windows 本机启动器即使没有网络，也能完成第一次打开；缓存完成后标准浏览器可在文件服务停止时继续启动。应用内嵌浏览器的停服刷新未通过，本版推荐使用 Edge/Chrome。

数据保存在当前浏览器的 IndexedDB：`xiaoxu-local / app-state / current`。沿用旧版备份格式，可从原“小序”导出后导入本版。不同浏览器、地址、端口和用户配置文件之间不会自动共享；固定使用 127.0.0.1:4178，迁移设备请通过“设置与备份”导出 JSON。导入替换数据前会确认。读取失败不会自动覆盖数据，写入顺序串行处理，保存失败会提示导出备份。

网页无法承诺浏览器完全退出后的准时通知，电脑关机时也无法提醒。需要这个能力时再单独开发操作系统通知适配。
