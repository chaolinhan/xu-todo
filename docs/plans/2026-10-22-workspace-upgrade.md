# 工作台与批量操作 Implementation Plan

**Goal:** 按已确认的第一阶段范围改善布局、详情编辑、草稿保护、批量操作和多行录入，并更新品牌图标。

**Architecture:** 保持 AppData 现有任务与重复模型。批量修改由纯函数一次性校验和提交，并保存可检测冲突的撤销补丁；草稿单独保存在当前浏览器 localStorage，不视为已保存任务，不进入任务备份。共享列表、看板、日历任务行接入同一选择状态。详情采用右侧抽屉，手机为全屏，头尾固定；延续暖白和朱红。

**Tech Stack:** React、TypeScript、Vite、现有 Lucide 图标与 IndexedDB，无新增在线服务或运行依赖。

## 1. 事务和多行解析

创建 src/lib/bulk-tasks.ts 及测试：优先级、项目、标签、日期、完成和恢复；全部先校验，重复完成只建一个后继；改期保留关闭的提醒和提醒偏移，更新重复锚点；撤销只恢复未被再次修改的任务与后继。多行解析保持单行的中文语法，预览后一次创建，不截断超长标题或静默跳过无效行。

## 2. 草稿与弹层

创建 src/hooks/useDraft.ts 与 useDialog.ts。关闭、Esc、外部点击和刷新后可以恢复草稿，保存或显式丢弃才清除；不同任务隔离，来源任务改变时提示旧草稿，不自动覆盖。提供浏览器存储失败提示。统一焦点约束、Esc层级与无滚动焦点恢复。TaskEditor 改用固定头尾的抽屉，常用属性紧凑排列，重复设置可展开。

## 3. 批量界面

创建 BulkToolbar，并在 App 中持有去重选择集合。TaskList、TaskBoard、CalendarPreview 共用选择属性；全选仅作用于当前可见范围，切换视图或选中日期退出选择。批量动作写入现有日志，支持撤销；混合完成状态只处理有变化的任务。

## 4. 工作台视觉和导航

提高文字对比度与可读字号，收紧标题与分组间距，统一列表/看板的工具栏基线；扩展现有紧凑模式。固定侧栏顶部与底部，仅中间滚动，收藏常用项目/标签/过滤器。看板移动入口收进菜单，保留触控和键盘可达性。导航和搜索变化回到顶部，关闭详情保持原位置。

## 5. 品牌与验收

新增 BrandMark 的 SVG 纸页勾选图形，更新加载态、favicon 与 PWA 图标。补充事务、草稿恢复、批量全选/范围、导入兼容、滚动以及多行创建测试。依次运行 npm test、npm run build、npm run build:pages，验证独立4179端口的桌面和390宽界面；保留4178原数据。更新使用指南和验证记录，检查敏感信息后提交、推送并确认 Pages 部署。
