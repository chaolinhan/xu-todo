# 预览的日、周、月速览

在现有“预览”内增加日、周、月分段切换，默认周视图，所选模式保存在现有本地偏好中。日视图呈现当天时间顺序的任务；周视图以周一开始的七日速览展示任务与数量；月视图用完整周的日历网格展示分布。日历选中日期后，下方提供该日完整任务清单，保留编辑、完成、恢复和添加任务。前后翻页按当前粒度移动，月末夹取日期避免跳过月份，“今天”定位本地当天。

按任务截止时间的本地日历日归类，沿用“显示已完成”偏好与优先级排序选择；无日期任务不混入日历，并提供前往全部任务的入口。重复任务显示已存在的实例，不凭空生成未来记录。快速添加从所选日期开始，并保持现有全局录入行为。周月计数与下方清单来自相同可见任务集合。

实现纯日历计算与测试，再接入展示、键盘日期选择、应用状态与偏好兼容，最后检查真实桌面/窄屏渲染及持久化。验证跨年周、闰年二月、连续月末翻页、本地日界、已完成与无日期排除、按选中日期添加和编辑日期后的重新归类。更新生产预览、说明和 Windows 离线包；不将 macOS 验收标为 Windows 实机通过。
