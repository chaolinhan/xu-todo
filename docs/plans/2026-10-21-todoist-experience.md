# 小序：Todoist 交互参考与离线网页版迭代

用户选择本轮优先贴近 Todoist 的界面与快速录入。基线为原聊天“构建离线 Todoist 网页应用”的 todo-ltn，现有提交 8361350。当前工作目录承接独立副本，保留原项目及数据。

推荐沿用已有 React / IndexedDB / 日历重复任务实现，重做界面并增加快速录入。直接修改 Todoist 安装包无法实现独立的完全离线产品；改为桌面封装会偏离本轮明确的网页形式，故不采用。

## 实施范围

1. 对本机 Todoist 9.31.0 做选定入口的静态分析并观察 UI，仅参考任务组织与交互，不复制其代码、素材或用户任务。
2. 使用白色任务主区、浅暖灰侧栏和克制红色强调，保留“小序”名称。提供收件箱、今天、预览、全部任务、项目、标签，列表内新建、搜索、已完成显示切换及列表密度选项。
3. 快速录入支持明确的中文相对日期、时间、p1–p4、已有 #项目 / @标签及常用重复规则；提交前显示可撤销的识别结果；未知项目和标签保留原文。保留完整任务编辑器。
4. 继续本地数据、备份和固定日历重复语义。禁止因读取本地数据库失败而自动写入示例数据；保存状态如实显示。
5. 构建时预缓存所有静态资源，包括字体。提供 Windows 可使用的静态站点包和运行说明，网页自身不依赖账号、云端或外部接口。

## 验证

日期与快速解析的边界测试、原有重复任务回归、完整构建，浏览器验收录入/完成/撤销/编辑/项目/搜索/备份，生产页断网刷新及离线新建持久化，移动宽度可用性。macOS 浏览器验收不等于 Windows 实机验收；浏览器完全退出后的准时通知仍不承诺。
