# 子任务与本地模板 Implementation Plan

**Goal:** 完成上一轮规划的第二阶段：一层子任务、进度与本地任务/项目模板；第三阶段日期模型和时间轴保持后续范围。

**Architecture:** 子任务作为Task内可选subtasks数组保存在同一事务中，不引入独立日期、项目或第二层嵌套。父任务完成时完成全部步骤；重新打开保留步骤状态；重复后继重置全部步骤；撤销恢复精确快照。模板保存独立的任务属性、标签名称、版块与相对日历日期，使用时预览并一次创建，引用全部重建。

**Tech Stack:** 现有React、TypeScript、IndexedDB、日期与选择器组件；无新运行依赖、账户或网络请求。

## 1. 数据与纯逻辑

修改src/types.ts、src/lib/backup.ts及测试，兼容无新增字段的备份，拒绝异常步骤和模板结构。新增src/lib/subtasks.ts、src/lib/templates.ts及测试。模板日期以最早截止日为第1天，按本地日历日平移，保留时分、提醒偏移和关闭状态，重复规则重新计算锚点。模板导入仅追加模板，不覆盖任务；限制文件和任务数量，拒绝失效版块引用和非法日期。

## 2. 子任务编辑和完成

新增SubtaskEditor组件，支持添加、编辑、删除、上下移动和勾选，修改随详情草稿保存；列表、看板、日历显示完成数/总数，搜索包含步骤标题。父任务与批量完成共用完成逻辑，撤销使用冲突检测快照，重复后继重置完成状态。通过组件和App测试验证草稿恢复、父任务完成/撤销与重复行为。

## 3. 模板库和预览

新增TemplateLibrary页面与TemplateApplyDialog。任务详情可保存当前内容为任务模板；项目/收件箱可保存未完成任务及版块为项目模板。模板库支持改名、说明、导入/导出和删除，提供内置示例作为可选入口；使用模板可选择起始日期、目标项目或创建新项目，生成前预览并确认。新项目、版块、标签和任务一次写入并记录日志，避免部分创建或覆盖已有内容。
