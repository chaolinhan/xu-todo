# 小序本地待办：产品与技术设计

小序是一款单用户、本机优先的轻量待办应用。第一阶段交付可安装的响应式 PWA，让用户能在 macOS 和 Windows 浏览器中直接体验；未来使用同一套 React 前端接入 Tauri 2，构建 Windows、macOS、iOS 与 Android 客户端。各设备的数据彼此独立，不设置账号、租户、后端服务或自动同步。

首版支持收集箱、今天、未来七天和全部任务视图，用户可以创建、编辑、完成和删除任务，并设置描述、截止日期与时间、四级优先级、项目、标签、提醒和日历规则重复任务。项目与标签均可在应用内创建。搜索覆盖任务标题和描述。设置页提供 JSON 备份导出与导入，作为本地数据迁移和恢复手段。首版明确不包含协作、评论、附件、子任务、自然语言日期解析和云同步。

网页阶段使用 IndexedDB 保存一个带版本号的应用状态快照，并通过 repository 接口隔离存储实现。提醒通过 reminder service 隔离：PWA 适配器在页面运行时检查到期提醒，优先发送浏览器系统通知，权限不可用时使用应用内提示；未来 Tauri 适配器改为将提醒注册给各操作系统。Service Worker 缓存应用壳与构建资源，使首次成功加载后可离线运行。

界面采用温暖、安静的编辑部式视觉语言，避免直接复制 Todoist。桌面端使用左侧导航、中央任务列表与模态编辑器；窄屏设备使用抽屉导航和底部主导航。交互需要覆盖键盘操作、清晰的焦点状态、减少动态效果偏好以及安全区适配。

测试分三层：纯函数单元测试覆盖视图筛选、日期归类和导入校验；TypeScript 与生产构建验证工程完整性；浏览器手工验证覆盖首次启动、任务全流程、刷新持久化、导入导出、响应式布局和离线重载。Windows/macOS/iOS/Android 的进程退出后通知属于后续 Tauri 阶段，必须在对应真实平台验证。
