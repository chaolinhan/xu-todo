# 分组与看板

已在 Todoist 本机应用的项目看板中观察：项目版块及“没有版块”各为一列，列标题含任务数量、版块菜单与列内添加任务入口；视图菜单将列表/看板布局与自动分组分开。自动分组选择含日期、添加日期、截止期限、优先级、标签。实际切换优先级后，任务跨版块汇集到优先级列；已恢复原“无”自动分组与原版块看板，任务未编辑。本次仅借鉴观察到的交互，不复制 Todoist 代码、素材或账户数据。

小序实现项目内自建版块（收件箱同样支持），可以创建、改名、调整顺序、删除但保留任务，并通过任务编辑器选择版块。列表与看板共享分组结果，支持按版块、日期、优先级、项目、标签或不分组。视图布局和分组按页面分别保存在本地，旧数据缺失字段时按默认值读取。标签分组中多标签任务可出现在多个组，显示总数时按任务去重。

看板采用横向列和白色任务卡片，支持点击编辑、完成恢复、列内添加及跨列拖动。拖动按当前分组更新关联属性；版块移动校验项目，项目移动清除原版块，标签移动只替换当前来源标签并保留其他标签，日期移动保留本地时间与默认提醒联动。每张卡提供“移动到分组”的下拉操作以支持键盘和触屏。日期“逾期”、“接下来”与已完成日期组不接受直接移动，避免把历史日期或完成状态当成任意可写目标。无分组不开放无意义移动；自动分组不伪造手动卡片排序。

日期预览保持日周月视图；其他任务列表提供布局/分组控件。重复任务新实例沿用版块关联，日志记录分组管理与任务移动；备份新增字段可选且严格验证。实施后验证分组覆盖、跨项目版块安全、删组保留、标签多组行为、移动提醒和重复锚点、旧备份、本地偏好、桌面拖动及窄屏可操作性，并更新生产预览与离线包。

实现与80项测试、生产构建通过；浏览器通过版块创建/改名/调整顺序、列表看板切换、列内新增、版块和优先级移动、完成恢复、日志及刷新保留，390宽文档溢出已修正。鼠标拖动由自动拖放事件测试覆盖，真实浏览器采用等价下拉移动验收。Windows ZIP已重新校验18个文件（199842字节），Windows启动器未实机测试。
