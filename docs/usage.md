# 使用指南

## 快速录入

输入 `明天下午3点 准备会议 #工作 @专注 p1`，小序会在保存前展示识别出的日期、项目、标签和优先级。各段之间使用空格分隔，项目与标签需要提前创建；点击识别结果可将其恢复为普通标题文字。未知内容与无效日期会保留在标题中，不会自动创建项目或标签。

日期与时间支持今天、明天、后天、下周一、周三、明确年月日、时分和中文时段；重复规则支持每天、每个工作日、每周三、每月、每年等。按 `Q` 打开快速添加，按 `/` 搜索全部任务，按 `Esc` 关闭当前弹层。搜索结果不受当前日历日期范围限制。

快速添加、截止时间和提醒时间使用统一日历组件。可以切换月份、选择快捷日期并输入时分，点击“应用日期”后才写入任务草稿。方向键移动日期，外部点击或 `Esc` 放弃尚未应用的选择。

优先级、项目、版块、重复规则、分组、排序和日志筛选采用统一选择菜单，优先级以彩色旗帜区分，P4 显示为“无优先级”。菜单支持方向键、Home、End 和回车，按 Esc 只关闭当前菜单并保留草稿，按 Tab 继续到下一个控件，也可以点击外部关闭。

将多行文字粘贴到任务名称，或点击“多行录入”，可按每行一项生成预览。每一行单独识别日期、项目、标签、优先级和重复规则；手动选择的日期和优先级应用到整批，共同描述会写入每项任务。预览确认后点击添加，或按 Ctrl / ⌘ + Enter；一次最多200项、10万字符，空行忽略。缺少标题或标题超过240字时整批不会添加，需要修改后再确认。

## 工作台与草稿

侧栏顶部和底部固定，中间导航可滚动。项目、标签和过滤器右侧的星标可将常用入口加入“收藏”，收藏随数据备份保存。切换页面或改变搜索条件会回到清单顶部；关闭任务详情保留原来的阅读位置。

桌面端从右侧打开任务详情，手机端为全屏。头部和保存区域固定，属性较多时可以独立滚动，重复规则通过“重复与高级设置”展开。点击关闭、“稍后继续”、按 Esc 或点击面板外部均保留草稿，重新打开或刷新页面后可继续编辑；保存成功或点击“丢弃草稿”才清除。不同任务的草稿相互独立。来源任务已经修改时，会提示存在旧草稿，由你决定是否恢复，不会直接覆盖新内容。

草稿仅保存在当前地址、当前浏览器的本地存储，不进入任务备份；它不代表任务已经保存。浏览器拒绝写入时会显示提示，请在关闭前保存或复制内容。恢复旧草稿后，保存会采用当前表单内容，请先检查。

## 批量操作

点击“选择任务”进入多选，可逐项勾选，或“全选当前范围”。选择按任务去重，多标签任务出现多次仍只处理一次；日历中仅选择当前选中日期下的清单。切换导航、搜索或日历日期会清除选择，隐藏的任务不会被修改。

底部操作栏支持设置日期、优先级、移动项目、添加标签、完成或恢复。添加标签保留已有标签；跨项目移动清除原版块；改期保留已关闭的提醒及原有提醒偏移。包含重复任务时不能整批清除日期，需要先取消重复。混合选择已完成和未完成任务时，“完成任务”仅处理未完成项，全部已完成时提供“恢复任务”。重复任务仍按原有规则生成一次后续实例。

批量修改和多行创建后，提示中的“撤销”保留12秒，可撤销最近一批操作；新的操作或提示可能替换该入口。撤销会保留其他任务的独立编辑，相关任务或新增重复实例已有后续修改时会拒绝覆盖。批量操作和撤销都会记录在活动日志中。

## 子任务

任务详情中的“子任务”支持一层清单，每项可勾选、改名、上下移动或移除。可粘贴多行，按Enter或点击加号加入清单，再保存整个任务。每个任务最多200项子任务，每项名称不超过240字；空白名称会阻止保存。尚未加入清单的输入也随草稿保留，需要先添加或清空后再保存。列表、看板和日历清单显示“已完成/总数”，全局搜索与过滤器的`search:`也会搜索子任务名称。

子任务是父任务内的步骤，不单独拥有日期、优先级、提醒或项目，也不单独计入任务总数。全部步骤完成后不会自动完成父任务；完成父任务会勾选剩余步骤，撤销可恢复此前的完整进度。恢复父任务保留步骤状态，编辑已完成任务并取消某个步骤后保存，会将父任务重新打开。重复任务的新实例保留步骤名称与顺序，全部重置为未完成。删除父任务会同时删除其步骤。

## 本地模板

在任务详情中点击“保存为任务模板”，会保存当前表单内容而不提交该任务的修改。在项目或收件箱页面点击“保存项目模板”，会保存所有未完成任务和全部版块；完成历史不纳入模板。侧栏“模板库”支持修改名称与说明、预览使用、单独导出和导入，内置示例仅在你确认使用后生成任务。每个模板最多200项任务、100个版块，本机最多保存1000份模板。

有日期的任务以最早截止日期为第1天记录日历日间隔。使用时选择起始日期，预览会展示实际日期和时分；无日期任务仍无日期，提醒偏移及关闭状态保留，重复规则按新日期重建。全部子任务重置为未完成。可创建新项目或选择已有项目，同名版块和标签复用，所有任务及步骤生成独立标识，原任务保持不变。确认后一次创建，日志记录新项目、版块、标签和任务。

单独模板文件为`xiaoxu-template`格式JSON，最大5MB，导入只追加模板，不应用到任务，也不替换当前数据。完整数据备份同时包含模板与子任务，兼容旧备份；备份和模板文件均未加密。删除模板不会删除已有任务，删除前可先导出。

## 日期、提醒与重复任务

日、周、月速览使用任务截止时间的本地日历日。周视图从周一开始，月视图以完整日历周展示；点击日期后可查看完整清单。为所选日期添加任务时默认使用当天09:00，可在保存前修改。月份翻页会将月末日期调整到目标月份的合法日期，不会跳过较短月份。

提醒默认跟随截止时间，手动清空后保持关闭。网页运行时会检查到期提醒；浏览器完全退出或电脑关机后，网页不保证准时通知。Windows 本机启动器尚未实机验收，原生操作系统提醒适配尚未实现。

重复任务完成时保留本次记录，生成一个后续实例；错过的周期不会逐个补建。月末与闰年日期保留原始日历锚点。恢复旧实例不会再次生成已经存在的后续实例。日历只展示已经存在的任务实例，不提前生成所有重复日期。

## 过滤器与标签

在“过滤器与标签”中保存查询，之后可以从侧栏直接打开。编辑器即时显示匹配数量，不存在的项目、标签或错误语法会明确提示，不会退化为匹配全部任务。

支持 `&`（同时满足）、`|`（任一满足）、`!`（排除）及括号，优先级依次为 `!`、`&`、`|`。例如 `active & (@专注 | p1)`、`#工作 & 无日期`、`completed`。含空格或运算符的名称需要双引号，例如 `@"等待 回复"`。

可用条件包括未完成（`active`）、已完成（`completed`）、全部（`all`）、p1–p4、今天、明天、逾期、未来7天、无日期、无标签、重复任务、`#项目名称`、`@标签名称` 和 `search:关键词`。编辑器帮助中也列出了英文写法。未来7天包含今天；日期条件比较截止日期，因此 `completed & 未来7天` 表示截止日期在未来七天内的已完成任务，不表示最近七天完成的任务。

过滤器独立匹配所有任务，只看待办时请加入 `active`。标签改名保留任务关联并同步过滤器引用；删除标签会移除任务上的关联，任务本身保留，引用该标签的过滤器需要重新编辑。

## 分组与看板

在项目或收件箱中通过“管理版块”创建分组，可以改名和调整顺序。删除版块会将任务放回“未分组”，不会删除任务。任务详情可选择所属版块，切换项目时会清除原版块，重复任务的新实例保留版块关联。

列表与看板共用分组规则，支持版块、日期、优先级、项目、标签及不分组。布局与分组按页面分别保存，搜索结果也有独立设置。多标签任务可能出现在多个标签组中，页面总数仍按任务去重。

卡片可点击编辑、完成或恢复，通过拖动或“移动到分组”控件跨列调整。列内添加会继承对应项目、版块、优先级、标签或日期。移动到其他项目时清除旧版块；标签之间移动只替换来源标签，保留其他标签，移动到“无标签”会清空标签。

日期分组可移入今天、明天、无日期；逾期、接下来、已完成组仅用于展示。日期移动保留时分及提醒偏移，关闭的提醒保持关闭，并更新重复规则的日期锚点。重复任务不能直接移入无日期，需要先取消重复。自动分组不提供列内手动排序，沿用日期或优先级排序设置。移动后不再符合当前视图条件的任务会退出当前页面，但仍然保留在数据中。

## 已完成任务与日志

独立“已完成”视图按完成时间倒序显示，并支持恢复任务。其他任务视图可在“视图”菜单中启用“显示已完成任务”；该菜单同时提供排序与紧凑显示设置。

活动日志记录启用日志功能后的任务添加、编辑、完成、恢复、删除、撤销，以及版块、标签、过滤器等组织结构的变化。历史记录保存当时的任务标题和项目快照，不会因后续任务删除而消失，也不会为升级前的操作补造记录。日志支持按操作、项目、时间范围和文字搜索，超过50条后可继续加载，并随备份导出。

## 数据迁移与备份

数据保存在当前浏览器的 `xiaoxu-local / app-state / current` 中。在线地址与 `127.0.0.1:4178` 本机地址使用不同存储空间；更换设备、浏览器或地址时，通过“设置与备份”导出和导入 JSON。

备份包含完整任务与日志，未加密。导入会在确认后替换当前数据，旧版缺少新增字段的备份仍可读取。读取本机数据失败时不会自动写入示例数据覆盖原记录；保存失败会显示导出备份提示。

生产构建缓存完整页面资源与字体，开发模式不启用缓存。首次打开在线版需要网络，本机便携目录可在无互联网环境下首次运行。离线缓存和浏览器存储会受浏览器实现及用户清理操作影响；应用内嵌浏览器的停服刷新未通过验证，离线使用推荐标准 Edge 或 Chrome。

## 打开应用

本机服务运行时访问 http://127.0.0.1:4178/；也可访问 https://chaolinhan.github.io/xu-todo/ 使用已部署版本。直接双击源码index.html得到的是file地址，不能运行应用。两个网页地址的数据各自保存在当前浏览器，迁移时使用“设置与备份”。第三阶段的日期分离、时间轴与高级重复尚未实现。
