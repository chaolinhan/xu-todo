## 未验证与限制

Windows PowerShell 启动脚本尚未在 Windows 实机运行。Windows ZIP 提供系统 PowerShell 的回环地址静态服务，无 Node.js 运行时依赖；不能把 macOS 上的 Chrome 验收当成 Windows 脚本验收。受管理的电脑可能限制脚本运行。

没有执行真实系统通知授权、浏览器完全退出后的提醒、Windows 桌面安装流程，也没有进行跨设备同步。本版为网页应用，浏览器进程完全退出后的准时通知仍不承诺。备份解析回归测试通过，覆盖式导入没有在真实用户数据上执行。
